# Changelog

All notable changes to the NOW Index project will be documented in this file.

## [1.0.0] - 2025-01-15

### Added
- Initial release of the NOW Quant Framework
- Core scoring engine with 10 factors
- Support for 20+ asset classes
- REST API with 17 endpoints
- "Momentum Please" website with dark-mode UI
- Interactive dashboard with charts
- Leaderboards (Top 10/25/50/100, Most Improved, Best in Class)
- Company profile pages with factor breakdown
- Comparison tool for side-by-side asset analysis
- Portfolio simulator
- Watchlist functionality
- Search and filter capabilities
- Historical score tracking
- SQLite database for persistence
- Hourly refresh pipeline
- Daily/weekly/monthly report generation
- Docker support with Docker Compose
- CI/CD with GitHub Actions
- Comprehensive test suite
- Example Jupyter notebook
- Full API documentation (Swagger UI + ReDoc)
- Professional README and contribution guide
